## OPX Parallax
 OPX Parallax is a mod that seeks to add Parallax Continued support to the full suite of OPX mods. 
 Find more about OPX [here](https://forum.kerbalspaceprogram.com/topic/225300-112x-planet-pack-outer-planets-expansion-opx/).
 
 ## Dependencies are:
 - OPX-Jool
 - OPX-Sarnus
 - OPX-Urlum
 - OPX-Neidon
 - Outer Planets Mod
 - OuterPararallax **(ONLY the common files, and version 0.6.2)**
 - Parallax Continued. The mod works with release 1.0.3, but will not support any of its features until post release.
 - **Including their dependencies. Please install them via CKAN to avoid mistakes.**
 
 If you find that it runs without any of the former 4, they haven't been added yet as this mod is in heavy WIP.
